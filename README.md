# 🚀 BMI Pro - Premium Fitness Dashboard

A modern and interactive BMI Calculator built using **HTML, CSS, and JavaScript** with advanced health insights, workout plans, diet recommendations, BMI tracking, and beautiful visualizations.

## 🌟 Features

### 📊 BMI Calculator
- Calculate BMI instantly
- Supports:
  - Height in cm or ft/in
  - Weight in kg or lbs
- Gender selection
- Activity level selection

### 📈 Advanced Insights
- BMI Category Detection
- Ideal Weight Range
- Weight Gain/Loss Suggestions
- Daily Water Intake Recommendation
- BMR Calculation
- Maintenance Calories
- Estimated Body Fat %

### 🎯 Visualizations
- Animated BMI Ring
- BMI Scale Graph
- Progress Trend Chart
- Interactive Gauge Indicator

### 🏋️ Workout Plans
Personalized workout plans for:
- Underweight
- Healthy Weight
- Overweight
- Obese

### 🥗 Diet Plans
Customized meal plans with:
- Macronutrient breakdown
- Daily meal suggestions
- Calorie estimates

### 📜 BMI History Tracking
- Stores previous BMI calculations
- Local Storage Support
- Export History to CSV

### 🎨 Modern UI
- Glassmorphism Design
- Dark/Light Mode
- Responsive Layout
- Particle Background Animation
- Toast Notifications

## 🛠️ Technologies Used
